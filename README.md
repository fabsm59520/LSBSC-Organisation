# 🏀 LSBSC South Lille — Application Installable (PWA) & Synchronisée Firebase

Application web progressive (**PWA installable** sur téléphone, tablette, PC et TV) conçue pour le **Lille Sud Basketball Sporting Club (LSBSC - South Lille)** avec synchronisation temps réel intégrée.

## ✨ Fonctionnalités intégrées
1. **Synchronisation Temps Réel pré-configurée :**
   - Connectée directement par défaut à la base Firebase du club (`https://lsbsc-ecran-default-rtdb.europe-west1.firebasedatabase.app/lsbsc.json`). Aucune configuration manuelle requise sur les appareils.
2. **Application Installable (PWA) :**
   - Bouton **« 📲 Installer »** directement dans l'interface pour ajouter l'icône **LSBSC Direct** sur l'écran d'accueil (Android, iPhone/iPad, Windows, Mac) en mode plein écran sans barre d'adresse.
   - Cache hors-ligne intelligent (`sw.js`) pour garder l'affichage actif même en cas de coupure Wi-Fi/4G dans la salle.
3. **Sélection du format au chargement :**
   - **🖥️ Écran TV Salle / PC (Paysage 16:9)** ou **📱 Téléphone (Version Allégée)**.
4. **Accès sécurisés par Code PIN :**
   - **Direct & Saisie des scores** (`5900`) et **Gestion Logos & Mascotte** (`9694`).
